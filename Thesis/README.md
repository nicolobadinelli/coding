# Cosmic Birefringence & Axion Dynamics #

This folder contains a Jupyter notebook containing a coherent numerical pipeline to study the background evolution of an axion-like field.

# Notebook Structure #
Evolution_with_CLASS.ipynb

Goal:
-
Solving the equation of motion (EOM) of a spectator axion field with a cosmological background computed through CLASS.

Contents:
- 
	1. Introduction to the physical problem and its variables
	2. Computation of the cosmological background using CLASS
	3. Computation of the EOM and plot
	4. Computation of the equation of state (EoS) and plot
	5. Computation of the density parameter and plot

Output / Importance:
-
This notebook produces an accurate evolution of the background field, its equation of state and density parameter.


# Requirements

    •	Python ≥ 3.9
    •	CLASS
    •	Standard scientific libraries: numpy, scipy, matplotlib, h5py
    •	Jupyter Notebook / JupyterLab
